# Домашнее задание

## Условие задачи
Написать программу, выводящую на экран заданную геометрическую фигуру, нарисованную с помощью заданного с клавиатуры символа. Предусмотреть возможность изменения размеров фигуры путем задания ее размеров в количестве символов пользователем.

## 1. Алгоритм и блок-схема

### Алгоритм
1. Начало функции. Получение символа sym и целого числа size (размер катета) в качестве параметров.
2. Начать внешний цикл по строкам с управляющей переменной i от 1 до size включительно с шагом 1.
3. Внутри первой строки начать внутренний цикл по столбцам с управляющей переменной j от 1 до i включительно с шагом 1.
4. На каждой итерации внутреннего цикла проверять условие контура фигуры:
	• Если текущая строка является последней (i == size), либо текущий столбец является первым (j == 1), либо мы находимся на диагонали (гипотенузе) фигуры (j == i), то перейти к шагу 5.
	• Иначе переходить к шагу 6.
5. Вывести в консоль заданный символ sym с помощью printf и перейти к шагу 7.
6. Вывести в консоль символ пробела " " с помощью printf.
7. Завершить текущую итерацию внутреннего цикла (шаг 3). После окончания внутреннего цикла для текущей строки выполнить переход на новую строку \n.
8. Завершить итерацию внешнего цикла (шаг 2). После вывода всех строк вернуть 0 в функцию main.
9. Конец функции.

## 2. Реализация программы
```c
printf("Введите символ: ");
if (scanf(" %c", &sym) == 1)
{
    printf("Введите размер: ");
    if (scanf("%d", &size) == 1 && size >= 2)
    {
        task3(sym, size);
    }
}

int task3(char sym, int size)
{
    for (int i = 1; i <= size; i++)
    {
        for (int j = 1; j <= i; j++)
        {
            if (i == size || j == 1 || j == i)
            {
                printf("%c", sym);
            }
            else
            {
                printf(" ");
            }
        }
        printf("\n");
    }
    return 0;
}
```
